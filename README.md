# Activité balance - version raisonnement visible

Version GitHub Pages avec zone de raisonnement très visible sur les défis où l'élève doit trouver une masse inconnue.

## Défis avec zone de raisonnement
2, 3, 4, 6, 9, 11, 13, 16, 18, 21, 23.

## Déploiement GitHub Pages
1. Dézipper le dossier.
2. Dans le dépôt GitHub, faire Add file > Upload files.
3. Déposer index.html, .nojekyll, README.md et code_iframe_ENT.txt.
4. Commit changes.
5. Le lien GitHub Pages reste le même.

En cas de cache, ouvrir le lien avec ?v=2 à la fin.
